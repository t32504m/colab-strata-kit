# Colab Manager

初めて使う場合は、先に [キット全体の導入手順](../README.md) に従ってダウンロード・配置と `install.cmd` による初期設定を済ませてください。このページは導入後の操作と仕組みを説明します。

WindowsのPowerShell 7 + Windows Formsで動く、Colab / Strata管理アプリです。
キットのフォルダ（以下 `<キット>`）の `Colab Manager.lnk` をダブルクリックして開きます（`install.cmd` が作ります）。
開くと状態を確認し、Colabランタイムが無ければ前回の起動設定でそのまま起動します（GPUを割り当て、CUを消費します）。既にランタイムがある場合は起動せず、状態/CU/APIの照会と停止監視だけを行います。
自動起動させたくないときは `Manager.ps1 -NoAutoStart` で開き、「起動」ボタンで起動します。`-Preview` では起動しません。
初回のモデル準備中は、取得・整合性検証・MTP準備/変換・メモリ読み込みの段階と経過時間を表示します。割合はファイルや工程ごとの値であり、全体の割合ではありません。前回約23分は参考値で、残り時間の保証ではありません。

## 使い方

1. 停止中に、モデル、16K / 32K / 64K / 128K / 256K、High-memory、MTP、画像入力を選びます。
2. 「無操作で停止（分）」（初期値30分）と、開くHarnessを選び、「起動」を押します。
3. 起動ログを表示し、準備完了後は選択したHarnessを開きます。
4. 終了時はアプリの「×」または「Colabを停止」。Colab CLIで停止を確認するまで待ちます。

「Colabを停止」だけでは管理画面は閉じません。停止コマンドの出力と「停止完了」が残ります。
「×」で終了を要求した場合は、停止確認のメッセージでOKを押してから終了します。
下部はコマンドを入力する端末ではなく、CLIの実行ログです。起動・停止中は出力を表示し、稼働中は画面更新時刻とAPI/SSHの状態を表示します。
Harnessを閉じてもColabは停止しません。停止は管理アプリから行ってください。
操作・終了要求・停止確認の履歴は `state/events.log` に保存します。
「実行コマンドを表示」でWindowsからのWSL呼び出しと主要な起動・停止コマンドを確認できます。履歴は `state/commands.log`。`function:` は共通スクリプトの関数呼び出しで、実装元のファイルパスも記録します。全シェル内部処理のトレースではなく、認証情報を含む環境変数やSSHペイロードは記録しません。以前の実行履歴を遡って復元するものではありません。
モデル準備中は約15秒ごとにStrataの詳細ログを取得して `state/strata-detail.log` に保存します。末尾1行だけでなく、取得・検証・変換・RAM読み込み・GPUキャッシュ充填などの出力を保存し、画面には末尾約4万文字を表示します。取得失敗時は前回のログを保持します。「新しい出力から」の秒数はログが変わってからの時間で、プロセスの生存や残り時間を保証する値ではありません。

稼働中の既存セッション `strata` も監視対象です。アプリを開くだけでは再起動しません。
「再接続」はモデルを保持したままSSH転送を復旧します。
「推論を再起動」はランタイムとモデルを保持してStrataだけ再起動します。
GPU / モデル / contextの起動設定を変える場合は一度停止してください。
High-memoryで要求した容量は保証せず、起動後のnvidia-smi実測を表示します。

## 停止の仕組みと限界

通常終了: 独立したGuardianが `colab stop -s strata` を実行し、`colab status` の「not found」を確認してから画面を閉じます。
アプリのプロセスが消えた場合: PIDとプロセス開始時刻で検知し、Guardianが停止を試みます。
起動の途中で閉じた場合: ランタイム割り当てを途中で強制終了せず、保存されたセッションIDを使って停止します。
ネットワーク・認証エラーは「停止済み」と扱いません。停止を再試行し、ログを残します。

PCの電源断・スリープ・OS強制終了、Guardian自体の強制終了では、ローカルの監視は動けません。
クラウド側の確実な課金停止を保証するものではありません。PCが復帰したらアプリを開き、状態を確認してください。
「無操作で停止」もローカル監視です（下の「使われていないときの停止」）。常時利用可能なクラウド側停止サービスは、この版には含まれません。

## CU表示

約60秒ごとにColab CLIのアカウント全体の残量・使用レートを取得します。
「アプリ起動後の減少」は残量差で、他セッションや追加購入の影響も含みます。
CU上限（0で無効）はアカウント残量の減少に基づきます。更新遅延と停止処理分の超過はあり得ます。
「この値を反映」で無操作の分数とCU差の基準を現在に更新します。

## 起動時間を短くするには

- 同じランタイムが残っていれば「再接続」を使う。モデル再取得は不要です。
- 設定を変えず推論だけ復旧したい場合は「推論を再起動」。ダウンロード済みのモデルと変換済みMTPを再利用します。
- 「MTPを使う」を外すと、初回の約5.2GBの追加取得と変換を省けます。生成速度が低下する場合があるため、短い実験向けです。速度改善量は未測定です。
- 小さい量子化版を選ぶと取得量・メモリ量を減らせますが、品質が変わります。
- 整合性検証は省略しません。Strataは検証済みファイルのマークを保持し、同一ファイルでは再検証を省けます。

今回のIQ3_Sは、GGUF約83.6GBに加えMTP・packがあり、データ全体は約87GiBでした。
新しいランタイムではこのローカルディスクが失われるため、再取得が発生します。
永続キャッシュにはモデル本体、検証マーク、変換済みMTP/packをまとめて保存する必要があります。
Google Driveやオブジェクトストレージは候補ですが、容量・転送速度・認証が必要で、Hugging Face直取得より速いとは限りません。
この版では追加ストレージの購入・大量アップロードは行っていません。

直近の通常A100は6.73 CU/時でした。25分の準備なら単純換算で約2.8 CUです。
レートは割り当てによって変わるため、アプリの実測表示を優先してください。

## 設定とログ

- 起動設定: `<キット>/strata-colab-cli/config.local.env`
- アプリ設定・ログ・監視記録: `<キット>/colab-manager/state/`
- DeepSeek Harness / Pi設定: APIから取得したモデルIDとcontextで、Colab用プロバイダーだけ同期。変更前を `.manager-backup` に保存します。
- 開いているHarnessは強制終了しません。モデルやcontextを変えた後はHarnessを再起動してください。
- 対象セッション名は `strata` 固定。他のColabセッションを一括停止しません。

緊急の手動停止:

```powershell
wsl -d Ubuntu -e bash -lc "colab stop -s strata"
wsl -d Ubuntu -e bash -lc "colab status -s strata"
```

## 開発・検証

`Test-Core.ps1` は状態解釈と停止条件を検証します。`Manager.ps1 -Preview` はColabや設定を変更しないUI確認用です。
`Test-Guardian.ps1` は実プロセスの異常終了・停止再試行を模擬CLIで確認します。
`test_bridge.py` は停止失敗・状態不明・起動失敗の後片付けを模擬CLIで確認します。
作成中の実環境確認では、JSONから復元した日時の二重タイムゾーン変換により意図せず1回停止しました。
日時型を保ってUTCへ変換するよう修正し、保存・復元後の期限と「期限前は停止しない」プロセステストを追加しています。

## コンテキストの既定値

ユーザー指定により次回起動は256K（262144トークン）。起動後は実際のAPIメタデータでHarness設定を同期します。256KのGPUメモリ・起動成功・速度は未検証です。GPU構成と他の設定は維持しています。

## 使われていないときの停止
- 起動からの固定時間ではなく、最後に使われてから「無操作で停止（分）」（初期値30分）たつと停止します。dsh や Pi で会話している間は延長され続けます。
- 「使われた」の判定: Colab側でGPU使用率を1秒ごとに見て、10%以上の秒を推論中とみなします（`bridge.sh` の `IDLE_GPU_UTIL`）。Managerは約60秒ごとにその時刻を取得します。
- モデル準備中は数えません（準備が90分を超えたら数え始めます）。
- SSHが切れるなどで測れない間は時刻が更新されないので、そのまま30分たつと停止します（費用を抑える側）。
- 外部からの停止指示: `state/stop-now.request` というファイルを置くと、「Colabを停止」ボタンと同じ扱いで停止します。Claude Code などから止めるとき用です。
  PowerShell: `New-Item <キット>\colab-manager\state\stop-now.request -Force`
